prompt = f"""
You are an assistant explaining PyCEFR Python code analysis.

Here is the PyCEFR analysis for {sample_name}:

{json.dumps(sample_result, indent=2)}

Explain the results in clear English for a beginner.

Include:
1. Total number of detected elements.
2. Number of elements at each detected CEFR level.
3. Most frequent CEFR level.
4. Highest detected CEFR level.
5. Python programming concepts identified by PyCEFR,
   what they mean, and their assigned levels.

Important rules:
- Use only the provided PyCEFR results.
- Do not invent Python concepts or element counts.
- Do not claim that the most frequent or highest level
  represents the overall difficulty of the program.
- Keep the explanation concise.
"""

    {"role": "user", "content": prompt}
]
